# Waste-Classification
A computer computer vision application that uses a CNN to classify waste. 

**This project is actively in development**


## How it Works
- Custom CNN architecture trained on 11,000 images 
across 4 waste categories achieving 85% validation accuracy. 
- Currently experimenting with transfer learning with a goal accuracy of 95%.

## Tech Stack
- Python, TensorFlow, Keras, OpenCV, NumPy

## Datasets
- https://www.kaggle.com/datasets/sumn2u/garbage-classification-v2?select=standardized_256
